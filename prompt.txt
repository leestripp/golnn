Artificial Life Simulation in C++ & OpenGL. gtkmm4 for the window.
ls3DRNN: Used for movement in 3D space.
* When Agents spawn, we should give them random amounts of neurons. We would need a MAX_LAYER_COUNT and MAX_NEURON_COUNT, so we don't have brains to large.
* When an Agent replicates, the child will get the parents brain with a small mutation.
* Inputs to the Agent brain. Instead of giveing position to food and agents, lets give a vector (direction) and distance.
When the last Agent dies, we should output its Agent type, hidden layer count and neuron cunt per layer. So we can track the Alpha Agent settings.
Agent types:
* Preditor : These agents drain the energy from other agents.
* Feeder: Standard agents, flee from Preditor aagents, feed and rest.
Feeder Feeding distance: feeders must be closer then 1 unit from food to eat. But detect food 20 units away.
Predator eating distance: predators must be closer the 1 unit from feeder agents to eat. But can detect them from 20 units away.
Random learning rates: Between 0.01 and 0.0005, to add more variation.
Colours: Only set base colours, then adjust based on energy level. Bright = high energy. dark = low energy, as a factor.
Predators Base Colour : Yellow (1.0f, 1.0f, 0.0f)
Feeders Base Colour : Deep Blue (0.0f, 0.0f, 1.0f)
